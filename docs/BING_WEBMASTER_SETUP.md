# Bing Webmaster Tools readiness

After the final domain is live, verify the site, submit `/sitemap.xml`, confirm IndexNow key verification, and review URL Inspection, crawl controls, search performance, Site Scan, crawl errors, and AI performance reporting where available. Use IndexNow only for changed URLs. Google-style metadata remains the shared baseline; Bing-specific diagnostics should be handled in Bing Webmaster Tools rather than through undocumented ranking tactics.
