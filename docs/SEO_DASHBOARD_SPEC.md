# SEO dashboard specification

Future read-only dashboard fields:

- Google: clicks, impressions, CTR, average position, indexed URLs.
- Bing: impressions, clicks, crawl errors, indexed pages, IndexNow status.
- Content: route, target keyword, status, traffic, last review, meaningful update date.
- AI discovery: referrer family, landing route, crawl status, citation/referral notes.

Keep credentials server-side, show source timestamps, and label all opportunity scores as prioritization heuristics rather than ranking predictions.
