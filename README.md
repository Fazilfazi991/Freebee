# freebee.world

freebee.world is a registry-driven collection of focused online utilities for documents, images, media, calculators, business workflows, and developer tasks. Browser-capable tools process files locally whenever possible.

## Development

Requirements:

- Node.js 22.22
- pnpm 9.14

```bash
pnpm install
pnpm dev
```

The local site is served by Remix and Vite. Set the optional public configuration in `.env.local`:

```bash
VITE_PUBLIC_SITE_URL=http://localhost:5173
VITE_PUBLIC_BETA=true
```

## Validation

```bash
pnpm typecheck
pnpm test
pnpm lint
pnpm build
```

## Architecture

- `app/lib/tools/registry.ts` defines categories and tools.
- `app/components/platform/` contains the shared site and tool interfaces.
- `app/lib/tools/` contains browser-side processing engines.
- `app/routes/` contains the public catalog, tool, category, legal, and operational routes.

See `docs/TOOLS_PLATFORM_ARCHITECTURE.md` for more detail.

## IncomeNow Instagram admin integration

This repository uses Remix and is deployed to the existing Vercel `freebee` project.
Cloudflare Pages configuration remains available for local development. The protected integration entry point is
`/dashboard`; the account screen is `/dashboard/integrations/instagram`. It signs in
the existing approved Supabase Auth user, then starts Instagram Login from
`/api/integrations/instagram/connect`. The exact callback is
`https://localhost:3000/api/integrations/instagram/callback` for local development.
The production callback is
`https://freebee.world/api/integrations/instagram/callback`.

Set the server-only values shown in `.env.example` in `.dev.vars` (Cloudflare dev
proxy) or the Vercel Production environment. Never prefix them with `VITE_` or commit real
values. `SUPABASE_SECRET_KEY` must be a Supabase secret/service-role key and is
used only by server routes. `META_INSTAGRAM_APP_ID` is the **Instagram App ID**
`2262233491193074`, not the Meta app ID. The secret is the Instagram App Secret
from the Instagram API setup screen. Generate `INSTAGRAM_ENCRYPTION_KEY_B64` as
32 random bytes encoded in Base64; keep a backup in a secret manager. Losing it
invalidates stored Instagram tokens and admin sessions. Rotating it requires a
planned re-encryption or reconnect. The admin user ID in `.env.example` identifies
the existing `fazil4fazi@gmail.com` Supabase Auth account. The app has no sign-up
route and does not accept other Supabase users as admins.

The reviewed `supabase/migrations/20260925162636_instagram_oauth_connections.sql`
was run in the specified Supabase project's SQL Editor on 2026-09-25. This manual
execution does not create a Supabase CLI migration-history entry. It enables RLS and revokes all
browser-role access to the connection and OAuth-state tables. Admin routes use
the server secret key; they return connection metadata but never the token. The
credential and the HTTP-only admin session are encrypted with AES-GCM.

Meta has both the local and production callbacks registered. In the Meta App Dashboard,
open **IncomeNow Reel Publisher → Instagram API → API setup with Instagram login
→ Business login settings → OAuth redirect URIs** to verify them. Only `instagram_business_basic` and
`instagram_business_content_publish` are requested. The accepted test account is
`@millionvault.com_` (Instagram account ID `17841426407668459`). No App Review,
Advanced Access, publishing, or Live mode change is required for this test.

Meta requires HTTPS for this localhost callback. Use a locally trusted certificate
for `localhost` (for example, one generated by `mkcert`) and place its key and
certificate under the ignored `.cert/` directory. Set
`INSTAGRAM_LOCAL_HTTPS_KEY_PATH` and `INSTAGRAM_LOCAL_HTTPS_CERT_PATH` in
`.env.local` to those files; Vite then serves `https://localhost:3000`. Installing
a local trust authority is a manual machine security change. Do not bypass a
browser certificate warning. The OAuth cookie is Secure and will not persist
over plain HTTP.

The Connect button starts the OAuth flow; it does not publish a Reel. Disconnect
removes the locally stored credential. To also revoke the authorization at Meta,
remove the app under the Instagram account's **Apps and websites** settings.
