# Future advertising placement strategy

No advertising network is active. Any future integration requires legal, consent, performance and accessibility review.

Safe candidates are below a completed workspace, between explanatory sections, or clearly separated from related tools. A desktop sidebar may be considered only when it does not compress the working area.

Ads must never appear beside upload, process, download, reset, signature, invoice totals, validation errors, or other action controls. They must be labelled, visually distinct, keyboard accessible, stable in size to avoid layout shift, excluded from print, and disabled during processing. Mobile layouts must keep an unmistakable separation from tool controls.
