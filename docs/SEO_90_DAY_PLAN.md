# 90-day organic growth plan

## Days 1–14: technical/indexation

Configure the final domain, verify HTTPS/host redirects, submit the sitemap, run a production crawl, validate robots/canonicals/JSON-LD, and measure representative mobile pages. Fix errors before publishing new routes.

## Days 15–30: existing-page optimization

Use the keyword map to improve titles, descriptions, intros, FAQs, formulas, limitations, breadcrumbs, category hubs, and relevant internal links for the top working tools.

## Month 2: clusters and approved programmatic routes

Publish up to five reviewed articles, add only approved conversion routes with keyword evidence, and monitor indexation and performance before scaling.

## Month 3: refresh and expansion

Refresh pages with real query data, earn links through useful assets, add the next cluster only where Search Console/Bing evidence supports it, and review crawler logs if production access exists.
