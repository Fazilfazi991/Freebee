# 90-day organic growth plan

## Days 1–14: technical/indexation

The final domain and connected GSC property are already known. Correct the live `www` to non-`www` canonical-host redirect, submit the 84-URL sitemap in GSC and Bing, refresh URL Inspection, and monitor the first indexed/not-indexed reasons. The production crawl already passes 84/84 routes; keep validating robots, canonicals, JSON-LD, and representative mobile pages. Fix host/indexation errors before publishing new routes.

## Days 15–30: existing-page optimization

Use real GSC queries, clicks, impressions, CTR, average position, and page-level impressions to improve titles, descriptions, intros, FAQs, formulas, limitations, breadcrumbs, category hubs, and relevant internal links for the top working tools. Until GSC data is available, optimize only the reviewed priority set and label all demand assumptions as hypotheses.

## Month 2: clusters and approved programmatic routes

Keep the five articles as drafts until editorial approval. Add only approved conversion routes with actual keyword evidence from GSC plus supplied Keyword Planner data, and monitor indexation and performance before scaling.

## Month 3: refresh and expansion

Refresh pages with real query data, earn links through useful assets, add the next cluster only where Search Console/Bing evidence supports it, and review crawler logs if production access exists.
